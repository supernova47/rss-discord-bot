# Changelog

All notable FeedFlow releases are listed here.

## 0.1.0 — 2026-10-23

First public GitHub release.

- Added a Discord bot and web dashboard for publishing RSS and Atom entries.
- Added feed discovery with a preview of recent entries.
- Added per-feed templates, layout, sender identity, media, timestamps, and link buttons.
- Added English and Russian dashboard localization.
- Added duplicate prevention and safe initialization of new feeds without posting the archive.
- Added Docker Compose deployment with Caddy-managed HTTPS and persistent SQLite storage.
- Added optional Telegram alerts and Moscow-time console logging.
- Redesigned the landing page and authenticated dashboard.
- Added Windows, VPS, Discord Developer Portal, backup, and update instructions.
