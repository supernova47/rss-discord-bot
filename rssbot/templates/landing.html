{% if language == 'en' %}Common questions{% else %}Частые вопросы{% endif %}

{% if language == 'en' %}Do I need to host the bot myself?{% else %}Бота нужно размещать самостоятельно?{% endif %}

{% if language == 'en' %}Yes. FeedFlow is self-hosted: run it on your own server or hosting and connect it to Discord.{% else %}Да. FeedFlow размещается самостоятельно: запустите его на своём сервере или хостинге и подключите к Discord.{% endif %}

{% if language == 'en' %}Which websites can I connect?{% else %}Какие сайты можно подключить?{% endif %}

{% if language == 'en' %}A site must provide a public RSS or Atom feed. FeedFlow checks that feed; it does not scan ordinary web pages.{% else %}У сайта должна быть публичная RSS- или Atom-лента. FeedFlow проверяет её, но не сканирует обычные страницы сайта.{% endif %}

{% if language == 'en' %}Will old posts be sent when I add a feed?{% else %}При добавлении ленты отправятся старые записи?{% endif %}

{% if language == 'en' %}No. On the first check, FeedFlow saves the latest entry as a starting point. Older entries are not sent.{% else %}Нет. При первой проверке FeedFlow сохраняет последнюю запись как начальную точку. Старые записи не отправляются.{% endif %}

{% if language == 'en' %}Can I follow a YouTube channel?{% else %}Можно следить за каналом YouTube?{% endif %}

{% if language == 'en' %}Yes. FeedFlow supports YouTube channel Atom feeds without requiring a separate YouTube API key.{% else %}Да. FeedFlow поддерживает Atom-ленты каналов YouTube без отдельного API-ключа YouTube.{% endif %}

{% if language == 'en' %}What Discord permissions are needed?{% else %}Какие права нужны боту в Discord?{% endif %}

{% if language == 'en' %}The bot needs permission to view the selected channel and manage webhooks there. To manage server feeds in the web panel, sign in with an account that can manage that server.{% else %}Боту нужны права просматривать выбранный канал и управлять вебхуками в нём. Для управления лентами в панели войдите через аккаунт с правом управлять сервером.{% endif %}

{% if language == 'en' %}Can I customize the Discord post?{% else %}Можно оформить публикацию по-своему?{% endif %}

{% if language == 'en' %}Yes. Configure Markdown and embed templates, a color, sender name and avatar, available feed images, and link buttons.{% else %}Да. Настройте шаблоны Markdown и embed, цвет карточки, имя и аватар отправителя, изображения из ленты и кнопки-ссылки.{% endif %}
