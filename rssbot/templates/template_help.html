Теги шаблонов публикаций

Тег — это имя в фигурных скобках. При отправке бот заменяет его значением из выбранной записи RSS.

ТегЧто подставитсяПример значения
{title}Заголовок публикации«Вышла новая версия приложения»
{url}Ссылка на публикациюhttps://example.com/news/42
{link}То же значение, что и {url}https://example.com/news/42
{description}Краткое описание без HTML-разметкиВ обновлении появились новые функции.
{content}То же значение, что и {description}В обновлении появились новые функции.
{author}Автор публикации, если указан в RSSКоманда проекта
{published}Дата публикации в UTC2026-10-21 09:30 UTC
{feed}Название ленты из настроек ботаНовости проекта
{image}Ссылка на изображение, включая картинку из HTML-описания RSShttps://example.com/news.jpg
{media}Ссылка на GIF или видео для отображения в карточке, если RSS её содержитhttps://example.com/animation.gif
{id}Стабильный ID публикации или её ссылкаnews-42

Пример карточки публикации

В поле заголовка укажите:

{title}

В поле описания:

{description}

[Читать на сайте]({url})

Если запись содержит описание «В обновлении появились новые функции» и ссылку, бот соберёт embed так:

Вышла новая версия приложенияВ обновлении появились новые функции.Читать на сайте ↗

Порядок блоков, разделители и кнопки-ссылки

Стрелками задайте порядок заголовка, изображения или GIF, описания и кнопок. Нажмите «＋» у нужного блока, чтобы вставить разделитель сразу после него. Разделитель можно перемещать стрелками или удалить. Пустые блоки и отсутствующее изображение пропускаются.

{% if language == 'en' %}

Use {url} in a button to open the current article, or enter a fixed HTTP(S) address. Each feed supports up to five buttons. Buttons open links and do not perform actions inside Discord.

{% else %}

В кнопку можно поставить {url}, чтобы открыть страницу текущей новости, или указать постоянный адрес HTTP(S). Для одной ленты поддерживается до пяти кнопок. Кнопки открывают ссылку и не выполняют действий внутри Discord.

{% endif %}

Бот ищет изображение в RSS-полях и HTML-описании записи. Если лента отдаёт MP4 вместо GIF, Discord может показать его как встроенное видео.

{% if language == 'en' %}Discord Markdown{% else %}Markdown в Discord{% endif %}

{% if language == 'en' %}

Use Markdown in the title, description, and message templates. For example:

{% else %}

Markdown можно использовать в заголовке, описании и тексте сообщения. Например:

{% endif %} 
**{title}**

{description}

[Read the article]({url})
{% if language == 'en' %}

Discord supports bold **text**, italic *text*, underline __text__, strikethrough ~~text~~, inline code `code`, quotes starting with >, and lists starting with -.

{% else %}

Discord поддерживает жирный **текст**, курсив *текст*, подчёркивание __текст__, зачёркивание ~~текст~~, код в строке `код`, цитаты с > и списки с -.

{% endif %}

{% if language == 'en' %}Publication time{% else %}Формат времени публикации{% endif %}

{% if language == 'en' %}

Each feed can show relative time, localized date and time, a full date with weekday, or both relative and exact time. Discord automatically formats these timestamps using each reader’s language and timezone.

The {published} template tag remains an explicit UTC value.

{% else %}

Для каждой ленты можно выбрать относительное время, местные дату и время, полную дату с днём недели или оба варианта сразу. Discord автоматически форматирует время на языке и в часовом поясе каждого читателя.

Переменная {published} в шаблоне по-прежнему выводит дату явно в UTC.

{% endif %}

Пример обычного сообщения

В поле «Текст сообщения над карточкой» можно написать:

🔔 Новая публикация в **{feed}**: {title}

Результат будет выглядеть так:

🔔 Новая публикация в **Новости проекта**: Вышла новая версия приложения
Если у записи нет значения для тега, он останется пустым. Для ссылок и форматирования можно использовать Markdown Discord.
